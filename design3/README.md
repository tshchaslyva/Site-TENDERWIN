# Етап 1 за інструкцією v3.0: три концепції сайту TenderWin

Прототипи, ізольовані від робочого сайту: форма нічого не надсилає, віджет дзвінка — макет, статистика не збирається, `noindex`.

| | Файл | Концепція |
|---|---|---|
| А | `dist/dosie.html` | «Відкрите досьє» — документ у першому екрані, пояснення підсвічують фрагменти |
| Б | `dist/shliakh.html` | «Шлях до рішення» — питання клієнта відкривають відповідні частини звіту |
| В | `dist/spokii.html` | «Точність і спокій» — специфікація послуги, великий перегляд зі змістом документа |
| | `dist/index.html` | Галерея й порівняння (`dist/gallery.html` — та сама сторінка для публікації) |

Звіт етапу 1: [`docs/v3-etap-1/zvit.md`](../docs/v3-etap-1/zvit.md).

## Перегляд

```
python3 -m http.server 8800        # із кореня репозиторію
# http://127.0.0.1:8800/design3/dist/
```

## Збірка

```
node design3/report/make-placeholder.mjs   # дві PDF-заглушки (до отримання справжніх звітів)
python3 design3/report/prepare.py          # PDF → сторінки WebP, фрагменти, зміст, перевірка знеособлення
python3 design3/build.py                   # src/*.html → dist/
```

- `content.py` — погоджені тексти v3.0 (розділ 8), однакові для всіх концепцій.
- `report/reports.config.json` — які PDF показувати і де в них фрагменти («підстава», «документ», «ризик», «рекомендація») та розділи змісту — за цитатами з тексту PDF.
- `src/viewer.js`, `src/viewer.css` — переглядач звіту: сторінки, масштаб, повний екран (`<dialog>`), зміст, PDF без реєстрації.
- `src/core3.js`, `src/core3.css` — спільна поведінка: поява з видимим станом спокою, FAQ, демо-форма зі станами, мобільна панель, місце віджета Zadarma.
- Шрифти (`dist/fonts`) — SIL OFL 1.1: Source Serif 4, Onest, IBM Plex Mono, Geologica, Fixel (MacPaw).
