# Ребрендинг TenderWin: п'ять концепцій (жовтень 2026)

Живі демонстраційні макети. На робочий сайт (`site/`) вони не впливають.

| № | Назва | Тема | Головний момент |
|---|-------|------|-----------------|
| 1 | Протокол | темна, графіт і золото | документ рішення, нитки до посилань, печатка |
| 2 | Кінетика | світла, швейцарська сітка | табло цифр, горизонтальний розділ «Метод» |
| 3 | Аналізатор | темна, інтерфейс продукту | консоль перевірки справи, порівняння документів |
| 4 | Атлас | світла, журнальна | розворот справи зі зносками, печатка вердикту |
| 5 | Ясно | світла, ультрамарин і соняшник | приклад розмови, спідометр шансів |

## Перегляд

```
python3 -m http.server 8800      # із кореня репозиторію
# відкрити http://127.0.0.1:8800/design2/dist/  (галерея) або …/dist/c1.html … c5.html
```

## Збірка

```
python3 design2/build.py              # src/*.html → dist/c1…c5.html, dist/gallery.html, dist/index.html
node design2/demo/make-demo.mjs       # dist/demo/pryklad-vysnovku-demo.pdf
```

- `src/c1.html … c5.html` — шаблони концепцій; місця `{{…}}` заповнює `build.py`.
- Затверджені тексти — у `build.py` (словник `T`) і `design/content.py` (FAQ), однакові для всіх концепцій.
- `cases.json` — три демонстраційні справи (дані вигадані, так і позначено на сторінках).
- `src/core.js`, `src/core.css` — спільна поведінка: поява під час прокрутки, лічильники, FAQ, демо-форма, мобільна панель, режим «менше руху».
- `src/gallery.html` — сторінка порівняння концепцій.
- Шрифти (`dist/fonts`) — SIL Open Font License 1.1: Fixel (MacPaw), Geologica, Onest, Unbounded, Playfair Display, Source Serif 4, Cormorant Garamond, IBM Plex Mono, JetBrains Mono.

Перевірено (Playwright, Chromium): ширина 320 / 390 / 1440 px без горизонтальної прокрутки, без помилок у консолі, режим `prefers-reduced-motion`.
