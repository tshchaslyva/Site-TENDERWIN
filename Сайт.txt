## 2. ADR-0017 — готовий до вставки в `04_DECISION_LOG.md`

```
## ADR-0017 — Сайт TenderWin: статичні файли на Cloudflare Pages

**Статус:** ACCEPTED (Vitalii, 2026-09-13)

**Контекст:** холодна розсилка вже посилається на tenderwin.in.ua
(константа SAYT у lead_machine), але сайту за цією адресою не було.
Лист, у якому вказано неіснуючий сайт, працює проти довіри сильніше,
ніж відсутність сайту в листі.

**Розглянуті варіанти:**
- A — статичні файли + Cloudflare Pages
- B — WordPress на українському хостингу. Відхилено: платний хостинг,
  постійні оновлення ядра й плагінів, регулярні зломи через застарілі
  плагіни. Обслуговування без окремої людини не тримається.
- C — Framer. Відхилено: ~15-20 USD/міс за власний домен, вендор-лок.
- D — Tilda. Відхилено: російське походження компанії. Для бізнесу
  у сфері українських державних закупівель це репутаційний ризик,
  непропорційний заощадженню.
- E — Cloudflare Workers (Static Assets). Відхилено на цьому етапі:
  ті самі результати, складніше в налаштуванні для непрограміста.
  Перехід можливий пізніше без зміни самого сайту.

**Рішення:** варіант A. DNS і хостинг обох доменів переносяться
в Cloudflare, тариф Free.

**Наслідки:** нульова вартість, нульове обслуговування, HTTPS і відкат
версій із коробки, сайт переноситься на будь-який хостинг за 10 хвилин
(вендор-локу немає). Мінус — зміна тексту вимагає редагування файла
й перезаливання папки; для односторінкового сайту прийнятно.

**Ризик, винесений в інструкцію окремим блоком:** перенесення NS без
копіювання MX/SPF/DKIM/DMARC ламає пошту tenderwin.com.ua, на яку
приходять відповіді з розсилки. Тиша у відповідях виглядає так само,
як слабка кампанія — дефект помічається не одразу.

**Лишається неперевіреним:** актуальність інтерфейсу Cloudflare на дату
виконання. Інструкція складена за офіційною документацією станом на
2026-09-13; назви пунктів меню Cloudflare періодично змінює.
```

## 3. Склад сайту (`tenderwin-site.zip` → папка `site`)

| Файл | Призначення |
|---|---|
| `index.html` | Увесь сайт одним файлом. Самодостатній: жодних зовнішніх шрифтів, скриптів чи стилів |
| `og.png` | Прев'ю 1200×630 для соцмереж і месенджерів |
| `robots.txt`, `sitemap.xml` | Індексація |
| `404.html` | Сторінка «не знайдено» |
| `_headers` | Заголовки безпеки для Cloudflare Pages |

### Структура сторінки

Шапка → герой → смуга про строк оскарження → «Коли ми потрібні» (3 картки)
→ «Підхід» (4 картки) → «Послуги і ціни» (8 позицій, 3 групи)
→ калькулятор → «Як працюємо» (4 кроки, перші два безкоштовні)
→ «Чого ми не обіцяємо» (4 пункти) → «Про нас» → FAQ (8 питань)
→ форма заявки + контакти → футер із політикою конфіденційності.
На мобільному — фіксована нижня панель «Подзвонити / Залишити заявку».

### Ціни на сайті (звірено з `lead_machine_v1.py`)

| Послуга | Ціна |
|---|---|
| Вимога про усунення порушень | 999 |
| Експрес-аналіз вимог ТД | 2 499 |
| Експрес-аналіз відхилення | 3 499 |
| Профіль замовника | 3 999 |
| Скарга на вимоги ТД | 6 999 (фікс) |
| Передтендерна перевірка | від 7 999 (формула A) |
| Скарга на рішення про відхилення | від 9 999 (формула B) |
| Кошториси | за домовленістю |

Калькулятор на сайті відтворює формули точно:
поріг 5 000 000; A = 7 999 / 0,0016 / стеля 10 999; B = 9 999 / 0,0020 / стеля 24 999.
**Перевірено звіркою з еталонною реалізацією на Python** у контрольних точках
(1,5 млн; 4 999 999,99; 5 000 000; 6 000 000; 6 874 375; 8 000 000; 12 499 500; 20 млн) —
розбіжностей немає.

> Якщо формули в системі змінюються, їх треба синхронізувати в `<script>`
> файла `index.html` (`var POROG`, `var A`, `var B`). Інакше сайт обіцятиме
> одну ціну, а оператор називатиме іншу.

## 4. Чого на сайті свідомо НЕМАЄ (правило 5 — не стверджувати невстановленого)

| Не вказано | Чому |
|---|---|
| Конкретна сума плати до АМКУ | Встановлюється законодавством і змінюється. Правило 7: не фіксувати правову істину в коді/контенті. У тексті — «суму називаємо до початку роботи» |
| Конкретні строки оскарження в днях | Те саме. Замість цифри — заклик подзвонити й порахувати строк для конкретної закупівлі (ще й працює на конверсію) |
| Кейси, відгуки, «виграно N справ» | Підтверджених даних немає. Вигадані цифри в цьому бізнесі коштують дорожче, ніж їх відсутність |
| Обіцянка перемоги в тендері | Прямо спростовується окремим розділом. Це головний диференціатор |

Згадка постанови КМУ № 565 від 06.05.2026 (чинна з 07.06.2026) подана **без сум**:
сам акт і дата набрання чинності підтверджені офіційним джерелом
(zakon.rada.gov.ua), конкретні тарифи перевірити не вдалося
(першоджерело закрите robots.txt, галузеві джерела — за платною стіною).
Позначено як `EXTERNAL_TECH_SPEC_NOT_VERIFIED` — на сайт цифри не потрапили.

## 6. Відкриті питання для Vitalii

1. **Публічна оферта** — на сайті свідомо немає. Потрібен юрист під реальні договори.
   Шаблон з інтернету брати не можна.
2. **Форма заявки через посередника.** Вміст заявки проходить через Web3Forms.
   Для контактів і номера закупівлі прийнятно; документи клієнта — категорично ні
   (на сайті це написано прямим текстом). Заміна на власний Cloudflare Worker —
   коли зʼявиться потреба.
3. **Кейси.** Після перших 5-10 справ додати знеособлені кейси.
   Найцінніший — той, де рекомендацією було **не оскаржувати**: він доводить
   позиціювання краще за будь-який текст.
4. **Хто ще має доступ до Cloudflare.** Після налаштування цей акаунт — ключ
   і до сайту, і до маршрутизації пошти. 2FA обовʼязкова.
