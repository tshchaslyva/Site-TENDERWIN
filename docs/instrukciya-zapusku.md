# TenderWin — запуск сайту на tenderwin.in.ua

**Для кого:** Віталій Щасливий. Інструкція розрахована на людину без досвіду програмування.
**Платформа:** Cloudflare Pages + Cloudflare DNS, тариф Free (0 грн). Чому саме вона — див. [порівняння хостингів](hosting-porivnyannya.md).
**Домени:**

| Домен | Для чого | Що з ним робимо |
|---|---|---|
| `tenderwin.in.ua` | **Сайт** | DNS переносимо в Cloudflare |
| `tenderwin.com.ua` | **Пошта** `vitalii@tenderwin.com.ua` | **Нічого не чіпаємо**: лишається в thehost як є |

**Дата:** 26 вересня 2026. Ця інструкція замінює попередні (`TENDERWIN_sayt_instrukciya.pdf/.docx`).

> Назви кнопок Cloudflare наведено англійською, як в інтерфейсі. Cloudflare час від часу перейменовує пункти меню,
> але логіка дій лишається тією самою.

## Крок 2. Акаунт Cloudflare (10 хвилин)

1. Відкрийте **dash.cloudflare.com** → **Sign up**.
2. Пошту вкажіть будь-яку, до якої маєте надійний доступ (наприклад, `vitalii@tenderwin.com.ua` або особистий Gmail).
3. Придумайте окремий надійний пароль.
4. Підтвердіть пошту листом від Cloudflare.
5. Увімкніть двофакторну автентифікацію: значок профілю праворуч угорі → **My Profile** → **Authentication** →
   **Two-Factor Authentication**. Збережіть коди відновлення.

> ⚠️ У цьому акаунті буде і сайт, і керування доменом. Двофакторна автентифікація обов’язкова.

## Крок 3. Запустити сайт у Cloudflare Pages (10 хвилин)

1. У Cloudflare в лівому меню: **Workers & Pages** (іноді **Compute (Workers)** → **Workers & Pages**) → **Create application**
   (або **Create**) → вкладка **Pages** → **Connect to Git** (**Import an existing Git repository**).
2. Виберіть **GitHub** → **Connect GitHub**. Відкриється GitHub: дозвольте доступ лише до репозиторію
   `tshchaslyva/Site-TENDERWIN` (**Only select repositories**) → **Install & Authorize**.
3. Виберіть репозиторій `Site-TENDERWIN` → **Begin setup**. Заповніть:

   | Поле | Значення |
   |---|---|
   | Project name | `tenderwin` |
   | Production branch | `main` |
   | Framework preset | `None` |
   | Build command | *залиште порожнім* |
   | Build output directory | `site` |

4. **Save and Deploy**. За 30–60 секунд з’явиться адреса на кшталт **`https://tenderwin.pages.dev`**.
   Якщо назва `tenderwin` уже зайнята, Cloudflare додасть до неї кілька символів — це нормально.
5. Відкрийте адресу й перевірте: сайт гортається, питання розкриваються, на телефоні внизу є панель «Замовити аналіз / Telegram».

Відтепер **кожна зміна в гілці `main` публікується автоматично** приблизно за хвилину.

<details>
<summary>Якщо з GitHub не виходить: запасний спосіб — перетягнути папку</summary>

1. На GitHub відкрийте репозиторій → зелена кнопка **Code** → **Download ZIP** → розпакуйте.
2. Cloudflare → **Workers & Pages** → **Create application** → **Pages** → **Upload assets** (**Drag and drop your files**) → назва `tenderwin`.
3. Перетягніть **вміст** папки `site` (так, щоб `index.html` лежав у корені) → **Deploy site**.

Мінус: кожну зміну доведеться заливати так само вручну. Такий проєкт потім не можна підключити до GitHub.
</details>

## Крок 4. Перенести DNS `tenderwin.in.ua` у Cloudflare (15 хвилин + очікування)

> Пошта `vitalii@tenderwin.com.ua` на іншому домені, тож цей крок її не зачіпає.
> **Домен `tenderwin.com.ua` у thehost не чіпайте.**

### 4.1. Подивіться, що зараз налаштовано для tenderwin.in.ua (2 хвилини)

У кабінеті **thehost.com.ua** → домени → `tenderwin.in.ua` → керування DNS. Зробіть знімок екрана списку записів.
Найімовірніше, там лише записи паркування або хостингу thehost (типи A, CNAME). Якщо побачите **MX** чи **TXT** — збережіть їх:
Cloudflare має перенести їх сам, а знімок знадобиться для звірки.

### 4.2. Додайте домен у Cloudflare

1. У Cloudflare: **Add a domain** (або **+ Add** → **Connect a domain** / **Existing domain**).
2. Введіть `tenderwin.in.ua` (без `https://` і без `www`) → **Continue**.
3. Виберіть тариф **Free** (0 $). Він унизу списку, його легко пропустити.
4. Cloudflare покаже знайдені DNS-записи:
   - записи **A / AAAA / CNAME** для `tenderwin.in.ua` і `www` (старі адреси паркування чи хостингу thehost) **видаліть**: сайт прив’яжемо на кроці 5;
   - записи **MX / TXT**, якщо вони є, **залиште**;
   - **Continue**.

### 4.3. Змініть NS-сервери в thehost

1. Cloudflare покаже **два NS-сервери** на кшталт `ada.ns.cloudflare.com` і `rob.ns.cloudflare.com`. У кожного акаунта вони свої. Скопіюйте обидва.
2. У кабінеті **thehost.com.ua** відкрийте домен `tenderwin.in.ua` → розділ **«DNS-сервери»** / **«NS-сервери»** / **«Змінити NS»**
   (назва залежить від версії кабінету).
3. **Видаліть** наявні NS thehost і **впишіть два сервери Cloudflare**. Саме замініть, а не додайте. Збережіть.
   Якщо не знаходите, де це робиться, напишіть у підтримку thehost:
   *«Прошу змінити NS-сервери домену tenderwin.in.ua на `…` та `…` (сервери Cloudflare). Домен tenderwin.com.ua не змінювати.»*
4. Поверніться в Cloudflare → **Check nameservers now**.

Далі чекаєте від 1 до 24 годин. Коли домен стане **Active**, Cloudflare надішле лист; статус видно й на головній сторінці домену.
Перевірити, як іде оновлення, можна на **dnschecker.org**: введіть `tenderwin.in.ua`, тип **NS**.

### 4.4. Одразу після Active: одна галочка

У Cloudflare → домен `tenderwin.in.ua` → **SSL/TLS** → **Edge Certificates** → **Always Use HTTPS** = **On**
(якщо вже увімкнено, нічого не робіть). Решту налаштувань SSL лишайте за замовчуванням.

## Крок 5. Прив’язати домен до сайту (5 хвилин)

Виконуйте тільки після того, як `tenderwin.in.ua` став **Active**.

1. **Workers & Pages** → проєкт `tenderwin` → вкладка **Custom domains** → **Set up a custom domain**.
2. Введіть `tenderwin.in.ua` → **Continue** → **Activate domain**. Cloudflare сам створить запис і сертифікат HTTPS.
3. Повторіть для `www.tenderwin.in.ua`.
4. Через 1–15 хвилин (зрідка до години) відкрийте `https://tenderwin.in.ua`: має бути ваш сайт із замочком в адресному рядку.

> ⚠️ Не створюйте запис для сайту вручну в розділі DNS: сайт видаватиме помилку 522. Тільки через **Custom domains**.

**Щоб `www` вело на адресу без `www`** (необов’язково, але правильно для Google): домен `tenderwin.in.ua` → **Rules** →
**Redirect Rules** → **Create rule** → шаблон **Redirect from WWW to root** (якщо шаблону немає: умова *Hostname equals
`www.tenderwin.in.ua`*, дія *Dynamic*, вираз `concat("https://tenderwin.in.ua", http.request.uri.path)`, код **301**,
**Preserve query string** увімкнути) → **Deploy**.

## Крок 6. Увімкнути форму заявки (10 хвилин)

Форма надсилає заявки через безкоштовний сервіс **Web3Forms** (до 250 заявок на місяць) на `vitalii@tenderwin.com.ua`.

1. Відкрийте **web3forms.com**, впишіть `vitalii@tenderwin.com.ua` → **Create Access Key**.
2. На пошту прийде **Access Key**, рядок на кшталт `a1b2c3d4-e5f6-7890-abcd-ef1234567890`.
3. Вставте ключ у сайт:
   - **найпростіше:** надішліть ключ Claude з проханням «встав ключ Web3Forms у сайт»;
   - **самостійно:** GitHub → `site/index.html` → олівець (**Edit this file**) → `Ctrl+F` → `ВСТАВТЕ-СЮДИ-ACCESS-KEY` →
     замініть **лише цей текст** на ключ (лапки лишаються) → **Commit changes**.
4. Через хвилину сайт оновиться. Надішліть тестову заявку: має з’явитися зелене «Дякуємо, заявку отримано», а на пошту має прийти лист.
   Якщо лист потрапив у «Спам», позначте його «Не спам».

**Поки ключа немає,** заявка не губиться: у відвідувача відкривається поштова програма з готовим листом на `vitalii@tenderwin.com.ua`.

> Ключ Web3Forms не секретний: він видимий у коді сторінки, так задумано сервісом.

## Необов’язково: tenderwin.com.ua у браузері → сайт

Хтось може набрати в браузері адресу з пошти, `tenderwin.com.ua`. Щоб він потрапив на сайт, **не переносьте NS цього домену**.
Попросіть підтримку thehost:

> *«Прошу налаштувати веб-переадресацію (301) з tenderwin.com.ua та www.tenderwin.com.ua на https://tenderwin.in.ua.
> MX, SPF, DKIM, DMARC та інші поштові записи не змінювати.»*

Після цього надішліть собі тестовий лист на `vitalii@tenderwin.com.ua`, щоб переконатися, що пошта працює.

## Як змінювати тексти й ціни

**Спосіб 1, найпростіший: попросити Claude.** Наприклад: «зміни ціну на 3 999 грн» або «додай питання: …».
Claude внесе зміну в репозиторій, і сайт оновиться сам.

**Спосіб 2: самостійно в GitHub (у браузері).**

1. Репозиторій → `site` → `index.html` → олівець (**Edit this file**).
2. `Ctrl+F` → знайдіть текст → змініть **тільки текст** між тегами.
3. **Commit changes** → **Commit changes**. Через ~1 хвилину зміна з’явиться на сайті (якщо ні, натисніть `Ctrl+F5`).

**Чого не чіпати:** усе між `<style>` і `</style>`, кутові дужки `< >` і лапки навколо значень, блок `application/ld+json` наприкінці.

> **Ціна фігурує в шести місцях `index.html`:** картка ціни, наліпка на першому екрані, два описи для пошуку й месенджерів
> (як `3 499`) і два поля розмітки для Google (як `3499`). Замініть усі. Ціна є і на прев’ю `og.png`: його Claude може перегенерувати.

**Відкат:** Cloudflare → **Workers & Pages** → `tenderwin` → **Deployments** → попередня робоча версія → **⋯** → **Rollback to this deployment**.

## Типові проблеми

| Симптом | Причина | Що робити |
|---|---|---|
| Домен понад добу «Pending» | NS у thehost замінено не повністю | Має бути рівно два сервери Cloudflare і жодного іншого; за потреби напишіть у підтримку thehost |
| Error 522 | Запис для сайту створено вручну в DNS | Видалити його й прив’язати домен через **Custom domains** |
| Браузер лається на сертифікат | Сертифікат ще випускається | Зачекати до години |
| Відкривається стара сторінка-заглушка thehost | Лишилися старі A/CNAME-записи | Видалити їх у Cloudflare → **DNS**, прив’язку робити лише через **Custom domains** |
| Форма відкриває поштову програму замість «Дякуємо» | Не вставлено ключ Web3Forms | Крок 6 |
| «Не вдалося надіслати» | Помилка в ключі або вичерпано 250 заявок на місяць | Перевірити ключ і лічильник у кабінеті Web3Forms |
| Зміни не видно | Кеш браузера або публікація ще триває | `Ctrl+F5`; перевірити **Deployments** |
