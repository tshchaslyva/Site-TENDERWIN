# TenderWin — запуск сайту на tenderwin.com.ua

**Для кого:** Віталій Щасливий. Інструкція розрахована на людину без досвіду програмування.
**Платформа:** Cloudflare Pages + Cloudflare DNS, тариф Free (0 грн). Чому саме вона — див. [порівняння хостингів](hosting-porivnyannya.md).
**Домен:** `tenderwin.com.ua`, зареєстрований на thehost.com.ua.
**Дата:** 26 вересня 2026. Ця інструкція замінює попередню (`TENDERWIN_sayt_instrukciya.pdf/.docx`, яка стосувалася домену tenderwin.in.ua).

> Назви кнопок Cloudflare наведено англійською, як в інтерфейсі. Cloudflare час від часу перейменовує пункти меню,
> але логіка дій лишається тією самою.

## 1. Підготовка. Не пропускайте: тут можна зламати пошту

Пошта `vitalii@tenderwin.com.ua` живе на тому самому домені, що й сайт. Коли DNS домену переходить у Cloudflare,
разом із ним мають перейти і **поштові записи**. Якщо їх не перенести, пошта перестане приходити, і ви не одразу це помітите:
тиша у відповідях виглядає так само, як слабка розсилка.

### 1.1. Доступи

- Логін і пароль від кабінету **thehost.com.ua** (там зареєстровано домен).
- Доступ до GitHub-акаунта, де лежить цей репозиторій (`tshchaslyva/Site-TENDERWIN`).

### 1.2. Випишіть поточні DNS-записи tenderwin.com.ua

У кабінеті thehost.com.ua знайдіть домен `tenderwin.com.ua` → розділ керування DNS (може називатися «DNS-записи», «Зона DNS», «Керування DNS»).
**Зробіть знімок екрана всього списку** і окремо випишіть:

| Тип запису | Що це | Що буде, якщо втратити |
|---|---|---|
| **MX** | Куди доставляти пошту | Пошта перестане приходити |
| **TXT** із `v=spf1` | SPF: хто має право надсилати листи від вашого імені | Листи падатимуть у спам |
| **TXT** з іменем на кшталт `…._domainkey` | DKIM: цифровий підпис листів | Листи втратять підпис, зросте спам-рейтинг |
| **TXT** з іменем `_dmarc` | DMARC: політика щодо підроблених листів | Погіршиться доставка розсилки |
| **CNAME** на кшталт `mail`, `autodiscover` | Налаштування поштових програм | Може перестати працювати пошта в Outlook чи на телефоні |

> Якщо поштові записи в thehost не показано, але пошта працює, спитайте в підтримки thehost, де обслуговується пошта домену
> і які записи для неї потрібні. Без цього списку до кроку 3 не переходьте.

### 1.3. Створіть акаунт Cloudflare

1. Відкрийте **dash.cloudflare.com** → **Sign up**.
2. Пошту вкажіть **сторонню** (наприклад, особистий Gmail), а не адресу на tenderwin.com.ua. Інакше, якщо пошта тимчасово ляже, ви залишитеся без доступу саме тоді, коли він найпотрібніший.
3. Придумайте окремий надійний пароль.
4. Одразу увімкніть двофакторну автентифікацію: значок профілю → **My Profile** → **Authentication** → **Two-Factor Authentication**. Збережіть коди відновлення.

> ⚠️ Після налаштування цей акаунт стане ключем і до сайту, і до домену, і (через DNS) до пошти. Двофакторна автентифікація обов’язкова.

## 2. Крок 1: запустити сайт у Cloudflare Pages

> **Перед цим:** зміни мають бути в гілці `main` репозиторію. Якщо сайт ще лежить в окремій гілці, попросіть Claude
> «створи pull request і злий у main» або злийте його в GitHub кнопкою **Merge pull request**.

1. У Cloudflare відкрийте **Workers & Pages** → **Create application** → вкладка **Pages** → **Connect to Git**.
2. Виберіть **GitHub** і дозвольте Cloudflare доступ до репозиторію `Site-TENDERWIN` (можна дати доступ лише до нього).
3. Виберіть репозиторій → **Begin setup**. Заповніть:

   | Поле | Значення |
   |---|---|
   | Project name | `tenderwin` |
   | Production branch | `main` |
   | Framework preset | `None` |
   | Build command | *залиште порожнім* |
   | Build output directory | `site` |

4. Натисніть **Save and Deploy**. За 30–60 секунд з’явиться адреса на кшталт **`tenderwin.pages.dev`**.
5. Відкрийте її й перевірте: сайт гортається, питання розкриваються, на телефоні внизу видно панель «Замовити аналіз / Telegram».

Відтепер **кожна зміна в гілці `main` публікується автоматично** приблизно за хвилину.

<details>
<summary>Альтернатива без GitHub: перетягнути папку</summary>

**Workers & Pages** → **Create application** → **Pages** → **Upload assets** → назва `tenderwin` → перетягніть **вміст** папки `site`
(так, щоб `index.html` опинився в корені) → **Deploy site**.

Мінус: кожну зміну доведеться заливати так само вручну. Крім того, проєкт, створений перетягуванням, потім не можна
підключити до GitHub, тож доведеться створювати новий проєкт. Тому рекомендую варіант із GitHub.
</details>

## 3. Крок 2: перенести DNS домену tenderwin.com.ua у Cloudflare

### 3.1. Додайте домен

1. У Cloudflare: **Add a domain** (або **+ Add** → **Existing domain**) → введіть `tenderwin.com.ua` → тариф **Free** (0 $, він унизу списку).
2. Cloudflare просканує наявні записи й покаже список.

### 3.2. Звірте поштові записи. Обов’язково

- Порівняйте список Cloudflare зі своїм знімком із пункту 1.2. **Кожен MX і кожен TXT (SPF, DKIM, DMARC) має бути на місці.**
- Чого бракує, додайте вручну: **Add record** → тип, ім’я, значення, пріоритет — точно як у thehost.
- Для MX, TXT і поштових CNAME перемикач **Proxy status** має бути **DNS only** (сіра хмарка).
- Якщо Cloudflare переніс старі A-записи для `@` чи `www`, які вели на хостинг thehost, **видаліть їх**. Сайт прив’яжемо на кроці 4.

### 3.3. Змініть NS-сервери в thehost.com.ua

1. Cloudflare покаже два NS-сервери, на кшталт `ada.ns.cloudflare.com` і `rob.ns.cloudflare.com`. Скопіюйте обидва.
2. У кабінеті thehost.com.ua відкрийте домен `tenderwin.com.ua` → розділ «DNS-сервери» / «NS-сервери» / «Делегування».
3. **Замініть** наявні NS-сервери на два сервери Cloudflare. Саме замініть, а не додайте до наявних. Збережіть.
4. У Cloudflare натисніть **Check nameservers**.

Зміна розходиться від 1 до 24 годин. Коли домен стане **Active**, Cloudflare надішле лист. Поки чекаєте, нічого робити не треба:
сайт працює на `tenderwin.pages.dev`, пошта — як раніше.

### 3.4. Одразу після Active перевірте пошту

- Надішліть лист із особистої пошти на `vitalii@tenderwin.com.ua`: має прийти за хвилину.
- Надішліть лист із `vitalii@tenderwin.com.ua` на особисту пошту й перевірте, що він не потрапив у спам.
- **Якщо пошта не приходить**, негайно поверніть у thehost старі NS-сервери: це відкотить усе назад. Потім спокійно звірте записи.

> Безпечніший час для цього кроку — вечір п’ятниці, коли не йде розсилка.

## 4. Крок 3: прив’язати домен до сайту

Виконуйте тільки після того, як домен став **Active**.

1. **Workers & Pages** → проєкт `tenderwin` → вкладка **Custom domains** → **Set up a custom domain**.
2. Введіть `tenderwin.com.ua` → **Continue** → **Activate domain**. Cloudflare сам створить потрібний запис і сертифікат HTTPS.
3. Повторіть для `www.tenderwin.com.ua`.
4. Через 1–15 хвилин перевірте: `https://tenderwin.com.ua`, `http://tenderwin.com.ua` (має перекинути на https), `https://www.tenderwin.com.ua`.

> ⚠️ Не створюйте запис для сайту вручну в розділі DNS: сайт видаватиме помилку 522. Тільки через **Custom domains**.

## 5. Крок 4: увімкнути форму заявки (на vitalii@tenderwin.com.ua)

Сайт складається лише з файлів, тож листи він надсилає через безкоштовний сервіс **Web3Forms** (250 заявок на місяць).

1. Відкрийте **web3forms.com**, впишіть `vitalii@tenderwin.com.ua` і натисніть створення ключа (**Create Access Key**).
2. На цю пошту прийде **Access Key**, рядок на кшталт `a1b2c3d4-e5f6-7890-abcd-ef1234567890`.
3. Вставте ключ у сайт одним зі способів:
   - **найпростіший:** надішліть ключ Claude з проханням «встав ключ Web3Forms у сайт»;
   - **самостійно в GitHub:** відкрийте `site/index.html` → значок олівця (**Edit**) → `Ctrl+F` → знайдіть `ВСТАВТЕ-СЮДИ-ACCESS-KEY` → замініть **тільки цей текст** на ключ (лапки лишаються) → **Commit changes**.
4. За хвилину сайт оновиться. Заповніть форму своїми даними й надішліть. Має з’явитися зелене «Дякуємо, заявку отримано», а на пошту має прийти лист.
5. Якщо лист потрапив у «Спам», позначте його «Не спам» і додайте відправника в контакти.

**Що буде, поки ключ не вставлено?** Заявка не загубиться: у відвідувача відкриється його поштова програма з уже заповненим
листом на `vitalii@tenderwin.com.ua`, залишиться лише натиснути «Надіслати».

**Що приходить у листі:** ім’я, телефон, e-mail (на нього можна просто натиснути «Відповісти»), ID закупівлі, код ЄДРПОУ/ІПН,
опис ситуації й позначка про згоду на обробку персональних даних.

> Ключ Web3Forms не секретний: він видимий у коді сторінки, так задумано сервісом. Він лише вказує, на яку пошту слати заявки.

## 7. Крок 6: статистика і Google

**Статистика (безкоштовно, без cookie):** **Workers & Pages** → `tenderwin` → **Metrics** → блок **Web Analytics** → **Enable**.
Банер про cookie не потрібен.

**Google Search Console:**

1. **search.google.com/search-console** → **Add property** → **Domain** → `tenderwin.com.ua`.
2. Google покаже TXT-запис. У Cloudflare: домен → **DNS** → **Add record** → Type `TXT`, Name `@`, Content — значення від Google → **Save**.
3. У Search Console натисніть **Verify**; за потреби зачекайте 10–15 хвилин.
4. **Sitemaps** → впишіть `sitemap.xml` → **Submit**.

## 8. Якщо у вас є домен tenderwin.in.ua або старі посилання

У попередній версії сайту головним був `tenderwin.in.ua`, і посилання на нього могли потрапити в шаблони холодних листів
(константа `SAYT` у lead_machine).

- **Оновіть посилання в листах** на `https://tenderwin.com.ua`.
- Якщо домен `tenderwin.in.ua` зареєстровано на вас, налаштуйте переадресацію: додайте його в Cloudflare (Free) →
  DNS: `A @ 192.0.2.1` і `A www 192.0.2.1`, обидва **Proxied** (помаранчева хмарка) → **Rules** → **Redirect Rules** → **Create rule**:
  умова *Hostname contains `tenderwin.in.ua`*, дія *Dynamic*, вираз `concat("https://tenderwin.com.ua", http.request.uri.path)`, код **301**.

## 10. Як змінювати тексти й ціни

**Спосіб 1, найпростіший: попросити Claude.** Наприклад: «зміни ціну на 3 999 грн» або «додай питання в FAQ: …».
Claude внесе зміну, і після злиття в `main` сайт оновиться сам.

**Спосіб 2: самостійно в GitHub (у браузері).**

1. Відкрийте репозиторій → папка `site` → файл `index.html` → значок олівця (**Edit this file**).
2. `Ctrl+F` → знайдіть текст, який хочете змінити → змініть **тільки текст** між тегами.
3. **Commit changes** → **Commit changes**. Через ~1 хвилину зміна з’явиться на сайті (якщо ні — `Ctrl+F5` у браузері).

**Чого не чіпати:** усе між `<style>` і `</style>` (оформлення), кутові дужки `< >` і лапки навколо значень,
блок `application/ld+json` наприкінці (розмітка для Google).

> **Ціна фігурує в шести місцях `index.html`:** картка ціни, наліпка на першому екрані, два описи сторінки для пошуку
> й месенджерів (усі — як `3 499`) і два поля розмітки для Google (`3499`). Знайдіть пошуком `3 499` і `3499` та замініть усі входження.
> Ціна є і на картинці-прев’ю `og.png`: її Claude може перегенерувати.

**Відкат, якщо щось зламалося:** Cloudflare → **Workers & Pages** → `tenderwin` → **Deployments** → попередня робоча версія → **⋯** → **Rollback to this deployment**.
Сайт повернеться за секунди. Зламати його назавжди практично неможливо.

## 11. Типові проблеми

| Симптом | Причина | Що робити |
|---|---|---|
| Error 522 | Запис для сайту створено вручну в DNS | Видалити його й прив’язати домен через **Custom domains** |
| Домен понад добу «Pending» | NS у thehost замінено не повністю | Має бути рівно два сервери Cloudflare і жодного іншого |
| Пошта перестала приходити | Не перенесено MX | Повернути старі NS у thehost, потім звірити записи за п. 1.2 |
| Листи падають у спам | Не перенесено SPF/DKIM/DMARC | Додати TXT-записи в Cloudflare, **DNS only** |
| Форма відкриває поштову програму замість «Дякуємо» | Не вставлено ключ Web3Forms | Крок 4 |
| Форма пише «Не вдалося надіслати» | Помилка в ключі або вичерпано 250 заявок на місяць | Перевірити ключ і лічильник у кабінеті Web3Forms |
| Зміни не видно | Кеш браузера або публікація ще триває | `Ctrl+F5`; перевірити **Deployments** у Cloudflare |

  на Cloudflare Worker. Це разове налаштування, яке Claude може зробити.
