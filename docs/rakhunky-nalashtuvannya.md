# Автоматичні листи з рахунком — налаштування

**Що робить сайт після натискання «Надіслати заявку»:**

1. Перевіряє дані: e-mail, ID закупівлі (UA-…), код ЄДРПОУ (8 цифр) або ІПН (10 цифр) і його контрольну цифру.
2. Шукає назву клієнта за кодом у ЄДР (сервіс Clarity Project). Для ФОП пише «ФОП Прізвище Ім’я По батькові».
3. Виписує рахунок у PDF із номером **TW-2026-09-27/1**: дата за Києвом, наприкінці — порядковий номер за день.
4. Надсилає **клієнту** лист-подяку з рахунком у вкладенні.
   Відповідь на цей лист приходить на `vitalii@tenderwin.com.ua`.
5. Надсилає **вам** на `vitalii@tenderwin.com.ua` усі дані заявки, знайдену назву й копію рахунку.
   Кнопка «Відповісти» в цьому листі відповідає клієнту.

**Захист від зловживань:**
- не більше 3 заявок з однієї адреси за годину і 40 за добу загалом;
- приховане поле-пастка для ботів;
- заявки приймаються тільки з вашого сайту.

**Запасний канал.** Поки пошту не підключено (крок 1), форма працює як раніше: заявка приходить вам через Web3Forms, а клієнту нічого не надсилається. Тому ці зміни можна публікувати одразу, нічого не зламається.

## Крок 1. Поштовий сервіс Resend (15 хвилин, безкоштовно)

Безкоштовний тариф — 3 000 листів на місяць, до 100 на день. Листи йдуть від імені `TenderWin <info@tenderwin.in.ua>`,
а відповіді клієнтів — на `vitalii@tenderwin.com.ua`. Пошту `tenderwin.com.ua` це **не зачіпає**.

1. Відкрийте **resend.com** → **Get Started** → зареєструйтеся з поштою `vitalii@tenderwin.com.ua`.
2. Ліве меню **Domains** → **Add Domain** → впишіть `tenderwin.in.ua` → регіон **Ireland (eu-west-1)** → **Add**.
3. Resend покаже 3–4 DNS-записи. Якщо є кнопка **Auto configure** / **Sign in to Cloudflare** — натисніть її й дозвольте доступ:
   записи додадуться самі. Якщо кнопки немає — додайте записи вручну:
   Cloudflare → домен `tenderwin.in.ua` → **DNS** → **Records** → **Add record** — кожен запис рівно як показує Resend
   (тип, ім’я, значення, пріоритет), **Proxy status: DNS only (сіра хмарка)**.
4. У Resend натисніть **Verify DNS Records**. За 5–30 хвилин статус домену стане **Verified**.
5. Ліве меню **API Keys** → **Create API Key** → назва `tenderwin-site`, доступ **Sending access**,
   домен `tenderwin.in.ua` → **Add**. Скопіюйте ключ, він починається з `re_`. Показується лише один раз.
6. Cloudflare → **Workers & Pages** → `site-tenderwin` → **Settings** → **Variables and secrets** → **+ Add**:
   - **Type:** `Secret`;
   - **Variable name:** `RESEND_API_KEY`;
   - **Value:** ключ `re_…`;
   - **Deploy** / **Save**.

> Рекомендовано для доставлення в «Вхідні»: Cloudflare → `tenderwin.in.ua` → DNS → **Add record** →
> `TXT`, Name `_dmarc`, Content `v=DMARC1; p=none;` → **Save**.

## Крок 2. IBAN і банк (1 хвилина)

Поки IBAN не вказано, клієнт отримує подяку **без рахунку** з обіцянкою надіслати його окремо.

**Найпростіше:** надішліть Claude IBAN і назву банку — він впише їх і підготує оновлення.

**Самостійно:** GitHub → файл `wrangler.jsonc` → олівець (**Edit**) → заповніть рядки:
```
"SELLER_IBAN": "UA00 0000 0000 0000 0000 0000 00000",
"SELLER_BANK": "АТ КБ «ПРИВАТБАНК»",
```
→ **Commit changes**. За хвилину Cloudflare опублікує зміни.

> Реквізити, ціну й тексти змінюйте **тільки у `wrangler.jsonc`**, а не в панелі Cloudflare:
> при кожному оновленні сайту значення з файлу перезаписують панель. Секрети (`RESEND_API_KEY`, `CLARITY_API_KEY`)
> навпаки живуть лише в панелі й не зникають.

## Крок 3. Назва клієнта з реєстру — Clarity Project (необов’язково, платно)

Щоб у рахунку автоматично стояла повна назва покупця («ТОВ …» або «ФОП …»), потрібен ключ API **Clarity Project**
(дані ЄДР). API продається пакетами запитів без строку дії; ціну уточніть на clarity-project.info → «Тарифи».
Один рахунок = один запит.

1. Зареєструйтеся на **clarity-project.info**, придбайте пакет API.
2. **clarity-project.info/me/api** → створіть ключ і скопіюйте.
3. Cloudflare → `site-tenderwin` → **Settings** → **Variables and secrets** → **+ Add** → `Secret`,
   ім’я `CLARITY_API_KEY`, значення — ключ → **Deploy**.

**Без цього ключа** рахунок виписується з кодом ЄДРПОУ/РНОКПП покупця, але без назви. Для оплати цього достатньо.
У листі вам буде позначка «Назва за реєстром: не знайдено».

## Крок 4. Перевірка

1. Відкрийте `https://tenderwin.in.ua` і натисніть **Ctrl+F5**. Заповніть форму: свій e-mail, будь-який реальний ID закупівлі,
   свій код (наприклад, ваш РНОКПП).
2. На сайті має з’явитися: «Дякуємо, заявку отримано! Рахунок № TW-… надіслано на …».
3. На вашу пошту прийдуть **два листи**: як клієнту (з PDF) і вам (заявка + копія PDF).
   Перший лист від нового відправника може потрапити в «Спам» — позначте «Не спам».

## Що змінюється де

| Що | Де |
|---|---|
| Реквізити, ціна, назва послуги, строк дії рахунку, адреса відправника | `wrangler.jsonc` → `vars` |
| Тексти листів | `worker/mail.js` |
| Вигляд рахунку | `worker/invoice.js` |
| Ліміти (3 за годину з однієї адреси, 40 на добу) | `wrangler.jsonc` → `LIMIT_PER_IP_HOUR`, `LIMIT_PER_DAY` |
| Ключі Resend і Clarity | Cloudflare → `site-tenderwin` → Settings → Variables and secrets |
| Журнал рахунків | Копія кожного рахунку — у вашій пошті (пошук «рахунок TW-») |

Найпростіше — попросити Claude: «зміни ціну на …», «зміни текст листа …».
