## Додаток А. Як замінити заглушку справжніми звітами

1. Покласти знеособлені PDF у `design3/report/real/` (оригінали з персональними даними в репозиторій не кладуться).
2. У `design3/report/reports.config.json` для кожного документа змінити `pdf`, `title`, `short`, `kind`, `placeholder: false` і цитати `start`/`end` — текст рядків PDF, якими починаються й закінчуються фрагменти та розділи змісту.
3. `python3 design3/report/prepare.py` — сторінки стають зображеннями, фрагменти й зміст знаходяться за цитатами, друкується перевірка знеособлення (метадані, анотації, вкладення, коди, пошта, телефони, ID закупівель).
4. `python3 design3/build.py` — оновлюються всі прототипи.
5. Для документа з даними клієнта — `private_documents` у конфігурації, `prepare.py --private` і `build.py --private`: результат лише в `design3/dist-private/` (не публікується).
