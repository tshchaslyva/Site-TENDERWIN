# Хостинг для tenderwin.in.ua — порівняння варіантів

**Станом на:** 26 вересня 2026
**Що розміщуємо:** односторінковий статичний сайт (папка `site/`, ~360 КБ). Бази даних, CMS і PHP не потрібні.
**Критерії:** найменша розумна ціна → співвідношення ціна/якість → зручність для людини без технічної освіти (як легко вносити зміни в наявний сайт).

> Ціни й ліміти зібрано з відкритих джерел (список — внизу). Тарифи TheHost перевірити напряму не вдалося:
> їхній сайт був недоступний з мого середовища, тож ціна взята з оглядів і позначена як орієнтовна.
> Перед оплатою будь-якого платного тарифу звірте ціну на сайті провайдера.

## Коротко: рекомендація

**Cloudflare Pages (тариф Free), підключений до вашого репозиторію GitHub.** Вартість — **0 грн**.
Платите лише за продовження домену в thehost.com.ua.

Чому саме він:

1. **Безкоштовно без підводних каменів.** Трафік і запити до статичних файлів не лімітуються. Комерційне використання дозволене.
2. **Змінювати сайт найпростіше саме тут.** Коли проєкт підключено до GitHub, будь-яка зміна файла публікується сама за ~1 хвилину. Для цього достатньо:
   - написати Claude «заміни ціну на …» — він внесе зміну, і сайт оновиться; або
   - відкрити файл у GitHub у браузері, виправити текст і натиснути «Commit changes».
   Жодних FTP, файлових менеджерів чи перезаливання папок.
3. **Відкат будь-якої зміни — один клік.** Cloudflare зберігає всі попередні версії.
4. **Швидкість і безпека.** Глобальна мережа CDN, HTTPS автоматично, захист від DDoS, статистика відвідувань без cookie.

**Єдиний технічний крок** — одноразово перенести DNS домену `tenderwin.in.ua` з thehost.com.ua на Cloudflare (~10 хвилин + до доби очікування).
Пошта `vitalii@tenderwin.com.ua` живе на іншому домені, тому це перенесення її не зачіпає. Домен `tenderwin.com.ua` лишається в thehost без змін.
Покроково це описано в [інструкції запуску](instrukciya-zapusku.md), розділ 2.

**Запасний варіант:** якщо принципово важливі «все в одному кабінеті», українська підтримка й ніяких змін DNS —
це **хостинг TheHost** (там уже ваш домен). Орієнтовно від ~65 грн/міс (~800 грн/рік). Сайт переноситься туди без змін.

## 1. Cloudflare Pages — основний варіант ✅

| Характеристика | Значення |
|---|---|
| Вартість | **0 грн** (тариф Free). Платний тариф Workers Paid (5 $/міс) для такого сайту не потрібен |
| Трафік | Не лімітується: запити до статичних файлів безкоштовні й безлімітні |
| Ліміти Free | 500 публікацій (збірок) на місяць; до 1 000 файлів, якщо завантажувати перетягуванням (у нас 14); 100 власних доменів на проєкт |
| Як оновлювати | **GitHub:** кожна зміна в репозиторії публікується сама за ~1 хв. **Перетягування:** папка `site` перетягується в браузері. Обидва способи — без програм і FTP |
| Відкат | Deployments → попередня версія → Rollback — за секунди |
| HTTPS, захист | Сертифікат автоматично; захист від DDoS; заголовки безпеки (файл `_headers` уже є в сайті) |
| Статистика | Cloudflare Web Analytics — безкоштовно, без cookie, банер згоди не потрібен |
| Форма заявки | Через Web3Forms: 0 грн, 250 заявок/міс, лист приходить на `vitalii@tenderwin.com.ua` |
| Пошта | Скриньок не надає. Пошта лишається в поточного провайдера — треба лише правильно перенести її DNS-записи |
| DNS | Для головного домену (`tenderwin.in.ua` без www) Cloudflare має керувати DNS: NS-сервери в thehost змінюються на cloudflare. Пошту на `tenderwin.com.ua` це не зачіпає |
| Мова інтерфейсу | Англійська. Інструкція з точними назвами кнопок — у [instrukciya-zapusku.md](instrukciya-zapusku.md) |
| Підтримка | На Free — документація та спільнота community.cloudflare.com |
| Прив’язка до платформи | Немає: сайт — звичайні файли, переноситься на будь-який хостинг за 10 хвилин |
| Нюанс 2026 року | Для **нових** проєктів Cloudflare радить платформу Workers, але Pages офіційно підтримується, і наявні проєкти працюють. Для статичного сайту різниці немає; якщо колись знадобиться, перехід на Workers займе ~15 хвилин без змін у сайті |

**Підсумок витрат:** хостинг 0 + форма 0 + статистика 0 + HTTPS 0 = **0 грн/рік**. Платите лише за продовження домену в thehost.com.ua.

## 3. GitHub Pages — безкоштовно, але із застереженням

| Характеристика | Значення |
|---|---|
| Вартість | 0 $ для публічного репозиторію. Для приватного — GitHub Pro (4 $/міс) |
| Ліміти | Сайт до 1 ГБ, «м’який» ліміт трафіку 100 ГБ/міс, 10 збірок на годину |
| Оновлення | Прямо в GitHub, де вже лежить сайт; публікується автоматично |
| Форми | Немає — потрібен Web3Forms |
| DNS | NS не міняти: A-записи додаються в thehost |
| Обмеження | Правила GitHub не дозволяють використовувати Pages як безкоштовний хостинг для онлайн-бізнесу чи сайтів, спрямованих переважно на комерційні операції. Сайт-візитівка платної послуги — у сірій зоні. Не працює файл `_headers` (заголовки безпеки) |
| Мінус | Щоб публікувати безкоштовно, репозиторій треба зробити публічним. Тоді всі файли, зокрема інструкції з вашими контактами, стануть видимими для всіх |
